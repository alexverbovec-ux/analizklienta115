Инструкция по использованию

1. Цветовая легенда полей

🟡 Жёлтый — выбор из списка / числовые показатели
🟢 Зелёный — данные карточки клиента, даты, важные комплаенс-события
🔵 Синий — расчётные доли (заполняются автоматически)
🔴 Красный — рекомендации (выбор из списка)
⚪ Серый — дополнительные пояснения от МКС

2. Общие правила заполнения

  • Жёлтые поля — обязательный выбор из списка (ОКВЭД, МТБ, ОПФ, система налогообложения, триггеры, схемы, рекомендации).
  • Зелёные поля — даты из карточки клиента и показатели, взятые из выписки.
  • Синие поля — доли считаются автоматически: показатель / общий оборот × 100%.
  • Серые поля — пояснения клиента или аналитика МКС по каждому триггеру.

3. Работа с триггерами

  • В первом и втором запросе триггеры выбираются из всплывающего списка по категориям: расходные операции, наличные, трудовые ресурсы, налоги, сомнительные операции/схемы.
  • ВАЖНО! Сомнительные схемы — кликабельные, под ними раскрывается полный список схем.
  • Для триггеров по трудовым ресурсам в столбце «Показатели» выбирается уровень зарплат из списка.
  • Для каждого триггера подбирается соответствующая рекомендация из списка.

4. Порядок работы

  • Обязательно создайте отдельную папку «ИИ» для удобства работы.
  • Заполните данные таблицы на основании выписок и документов клиента.
  • Перейдите в ИИ-стратег и вставьте ваш запрос (промпт) в строку.
  • ОБЯЗАТЕЛЬНО приложите Word-файл (ваш ПРОМПТ).
  • ОБЯЗАТЕЛЬНО приложите Excel-файл (заполненная таблица по клиенту).
  • Нажмите Enter или стрелку в строке для формирования ответа.

5. Итоговый формат запроса к ИИ

ИТОГ: в одном сообщении от вас должно быть:
1. Задание фразой;
2. Word-файл (промпт);
3. Excel-файл (заполненная таблица по клиенту).

6. Важные нюансы

  • Если графы с контрагентами и схемами остаются пустыми (нет триггеров с ними) — их не нужно копировать в ИИ.
  • При наличии пояснений или дополнительной информации из документов — вносите их в свободном режиме в серые поля.
  • Не забывайте указывать значения общего оборота — это нужно для корректного автоматического расчёта динамики и долей.
  • Старайтесь называть Excel-файлы по клиентам, сокращая их наименование, например: «Таблица для анализа ООО Торг Пром». Это нужно для работы в одном чате с ИИ, чтобы ответ генерировался за 2–3 минуты на уже обученном чате.
